# Second Brain Gmail MCP

This is a personal-use OAuth application connecting the [gmail-mcp](https://github.com/shinzo-labs/gmail-mcp) tool to Kevin Holloway's own Gmail accounts, for use with Claude Code as part of a personal knowledge-management ("second brain") system.

It is not a public product. It is not used by, and does not request data from, anyone other than the account owner.

See [PRIVACY.md](./PRIVACY.md) for the privacy policy.
