# Privacy Policy

**Last updated: 2026-09-26**

This application ("Second Brain Gmail MCP") is a personal-use tool built and operated solely by Kevin Holloway for his own Gmail accounts. It is not distributed to, installed by, or used by any other person or organization.

## Data access

The application uses the Gmail API to read, organize, and manage email (including labeling, archiving, and deleting messages) on the account holder's own Gmail accounts, at the account holder's direction, via an AI assistant (Claude) running locally under the account holder's control.

## Data storage

Email data is not stored by this application beyond what is necessary to service the immediate request. OAuth tokens are stored locally on the account holder's own machine and are never transmitted to any third party.

## Data sharing

No data accessed through this application is sold, shared, or transmitted to any third party.

## Contact

Questions about this application can be directed to the repository owner via GitHub.
